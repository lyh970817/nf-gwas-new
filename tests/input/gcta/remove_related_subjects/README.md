# REMOVE_RELATED_SUBJECTS Test Data

## Overview
This directory contains both **input** and **output** files for the `REMOVE_RELATED_SUBJECTS` process test. These files are used to test filtering of related individuals from GRM using GCTA.

## Files

### Input Files (Merged GRM)
- **gcta_grm_0.grm.id** - Sample IDs for merged GRM (all individuals)
- **gcta_grm_0.grm.bin** - Merged GRM matrix binary
- **gcta_grm_0.grm.N.bin** - Sample overlap counts
- **Source**: Copied from `merge_grm_parts/` directory (output from MERGE_GRM_PARTS)
- **Purpose**: Test filtering of related individuals (kinship > 0.05)

### Output Files (Unrelated GRM)

#### Test Output: "Should filter related individuals from GRM"
- `gcta_grm_0_unrel05.grm.id`: Sample IDs for unrelated subset (kinship < 0.05)
- `gcta_grm_0_unrel05.grm.bin`: Binary GRM matrix (unrelated subset)
- `gcta_grm_0_unrel05.grm.N.bin`: Sample overlap counts (unrelated subset)
- `gcta_grm_0_unrel05.log`: GCTA log file from relatedness filtering

## Process Details
**Process**: `REMOVE_RELATED_SUBJECTS`
**Tool**: GCTA
**Function**: Filters related individuals from GRM using GCTA remove-related-subjects option
**Relatedness Threshold**: kinship coefficient < 0.05 (hence `_unrel05` suffix)
**Input**: GRM files from merge_grm_parts or adjust_grm
**Output**: GRM files with `_unrel05` suffix containing only unrelated individuals

## Test Coverage
- ✅ Test Case: Filter related individuals with kinship threshold 0.05

## Biological Significance
The threshold kinship < 0.05 corresponds to removing pairs with approximately 2nd-degree or closer relationships:
- 0.25 = First-degree relatives (parents, siblings, children)
- 0.125 = Second-degree relatives (aunts, uncles, grandparents)
- 0.0625 = Third-degree relatives (cousins)
- 0.05 = Approximate threshold for removing beyond third-degree relationships
