# MERGE_SNP_GROUPS Test Data

## Overview
This directory contains both **input** and **output** files for the `MERGE_SNP_GROUPS` process test, which merges SNP group files across chromosomes for GREML-LDMS analysis.

## Files

### Input Files (Per-Chromosome SNP Groups)
- **chr01.vcf_snp_group1.txt** - Chromosome 1 high LD SNPs (group 1)
- **chr02.vcf_snp_group1.txt** - Chromosome 2 high LD SNPs (group 1)
- **chr01.vcf_snp_group3.txt** - Chromosome 1 low LD SNPs (group 3)
- **chr02.vcf_snp_group3.txt** - Chromosome 2 low LD SNPs (group 3)
- **Source**: Copied from `calculate_ld_scores/` directory (output from CALCULATE_LD_SCORES process)

### Output Files (Merged SNP Groups)
- **snp_group1.txt**
  - **Source**: Merged from `chr01.vcf_snp_group1.txt` + `chr02.vcf_snp_group1.txt`
  - **Description**: High LD SNPs (highest quartile) from chromosomes 1 and 2
  - **Use**: Input for MAKE_GRM_PART to create GRM for high-LD SNP partition
  - **Test**: First test case in `merge_snp_groups.nf.test`

- **snp_group3.txt**
  - **Source**: Merged from `chr01.vcf_snp_group3.txt` + `chr02.vcf_snp_group3.txt`
  - **Description**: Low LD SNPs (third quartile) from chromosomes 1 and 2
  - **Use**: Input for MAKE_GRM_PART to create GRM for low-LD SNP partition
  - **Test**: Second test case in `merge_snp_groups.nf.test` (with snapshot)

## Process Details

**Process**: `MERGE_SNP_GROUPS`
**Location**: `modules/local/gcta/merge_snp_groups.nf`
**Purpose**: Concatenate SNP group files across chromosomes for genome-wide partitioned heritability

**Input Format**: 
```groovy
tuple val(group_num), path(snp_group_files)
```

**Output Format**:
```groovy
tuple val(group_num), path("snp_group${group_num}.txt")
```

**Operation**: Simple concatenation via `cat`

## Test Coverage

✅ **Test 1**: "Should merge SNP group files across chromosomes"
- Merges group 1 (high LD) from chr01 and chr02
- Validates tuple structure and file existence

✅ **Test 2**: "Should handle different group numbers"  
- Merges group 3 (low LD) from chr01 and chr02
- Includes snapshot validation

## Workflow Context

These merged SNP groups are used in the GCTA GREML-LDMS workflow:

```
CALCULATE_LD_SCORES → MERGE_SNP_GROUPS → MAKE_GRM_PART → MERGE_GRM_PARTS → RUN_REML
```

This enables estimation of heritability contributions from SNPs with different LD properties.

## Data Source
- **Input Files**: Copied from `tests/input/gcta/calculate_ld_scores/` (CALCULATE_LD_SCORES outputs)
- **Output Files**: Generated by running `nf-test test tests/modules/local/gcta/merge_snp_groups.nf.test`
- **Test Data**: Self-contained in this directory for `merge_snp_groups.nf.test`
