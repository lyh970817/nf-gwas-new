## Process Details

### Process: RUN_FASTGWA_MLM

**Location**: `modules/local/gcta/run_fastgwa_mlm.nf`

**Inputs**:
1. `tuple val(chr_num), val(filename), path(plink_pgen), path(plink_psam), path(plink_pvar), val(range)` - PLINK2 genotypes
2. `tuple path(sparse_grm_id), path(sparse_grm_sp)` - Sparse GRM files
3. `path phenotypes_file` - Phenotype file (no header)
4. `path qcovariates_file` - Quantitative covariates (optional)
5. `path covariates_file` - Categorical covariates (optional)

**Outputs**:
- `path "*.fastGWA"` - Association test results

**Command**:
```bash
gcta \
    --pfile chr01.vcf \
    --grm-sparse gcta_grm_0_sp \
    --fastGWA-mlm \
    --pheno phenotype.noheader.txt \
    [--qcovar covariates.quant.noheader.txt] \
    [--covar covariates.cat.noheader.txt] \
    --thread-num ${task.cpus} \
    --out chr01.vcf_phenotype.noheader
```

## File Format Details

### Sparse GRM Format (`.grm.sp`)
```
row col value
0   0   0.98092675
1   1   1.0498329
2   2   0.96896255
...
```
- 0-indexed row and column IDs
- Only values > sparsity cutoff (0.05) are stored
- Symmetric matrix (only lower triangle stored)

### Phenotype Format (`.txt`, no header)
```
FID IID Y1 Y2
1   1   1.648   2.277
2   2  -2.674  -1.537
3   3   0.218   0.437
...
```

### Covariate Format (`.txt`, no header)
```
FID IID V1 V2
1   1   1.938   0.153
2   2  -1.634  -0.190
3   3   0.086   0.143
...
```

### FastGWA Output Format (`.fastGWA`)
Standard GCTA FastGWA format with columns:
- CHR: Chromosome
- SNP: Variant ID
- POS: Position
- A1: Effect allele
- A2: Reference allele
- N: Sample size
- AF1: Allele frequency
- BETA: Effect size
- SE: Standard error
- P: P-value

## Notes

- **Sparse GRM**: Essential for computational efficiency in large datasets
- **No Header Required**: GCTA expects phenotype/covariate files without headers
- **Covariates**: Separate files for quantitative (`--qcovar`) and categorical (`--covar`)
- **Sample Size**: 500 samples is minimal for testing; real datasets typically have 10k-1M samples
