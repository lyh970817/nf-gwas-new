# ADJUST_GRM Test Data

## Overview
This directory contains both **input** and **output** files for the `ADJUST_GRM` process test. These GRM files have been adjusted for incomplete tagging using GCTA.

## Files

### Input Files (Merged GRMs)

#### For Test 1: No SNP Groups
- **gcta_grm_0.grm.id** - Sample IDs for merged GRM (all SNPs)
- **gcta_grm_0.grm.bin** - Merged GRM matrix binary
- **gcta_grm_0.grm.N.bin** - Sample overlap counts
- **Source**: Copied from `merge_grm_parts/` directory (output from MERGE_GRM_PARTS)
- **Purpose**: Test adjusting GRM without SNP group filtering

#### For Test 2: With SNP Groups
- **gcta_grm_1.grm.id** - Sample IDs for merged GRM (SNP group 1)
- **gcta_grm_1.grm.bin** - Merged GRM matrix binary (SNP group 1)
- **gcta_grm_1.grm.N.bin** - Sample overlap counts
- **Source**: Copied from `merge_grm_parts/` directory (output from MERGE_GRM_PARTS)
- **Purpose**: Test adjusting GRM with SNP group filtering

### Output Files (Adjusted GRMs)

#### Test 1 Output: gcta_grm_0_adj
- `gcta_grm_0_adj.grm.id`: Sample IDs for adjusted GRM (no SNP group filtering)
- `gcta_grm_0_adj.grm.bin`: Binary GRM matrix (adjusted)
- `gcta_grm_0_adj.grm.N.bin`: Sample overlap counts (adjusted)
- `gcta_grm_0_adj.log`: GCTA log file from adjustment

#### Test 2 Output: gcta_grm_1_adj
- `gcta_grm_1_adj.grm.id`: Sample IDs for adjusted GRM (with SNP group 1 filtering)
- `gcta_grm_1_adj.grm.bin`: Binary GRM matrix (adjusted)
- `gcta_grm_1_adj.grm.N.bin`: Sample overlap counts (adjusted)
- `gcta_grm_1_adj.log`: GCTA log file from adjustment

## Process Details
**Process**: `ADJUST_GRM`
**Tool**: GCTA
**Function**: Adjusts GRM for incomplete tagging by GCTA reml --adjust-grm option
**Input**: GRM files from merge_grm_parts
**Output**: Adjusted GRM files with `_adj` suffix
