## Process Details

**Process**: `MERGE_GRM_PARTS`
**Location**: `modules/local/gcta/merge_grm_parts.nf`
**Purpose**: Combine partitioned GRM calculations into a single genome-wide GRM

**Input Format**:
```groovy
tuple val(nparts_gcta), val(snp_group), path(grm_ids), path(grm_bins), path(grm_Ns)
```

**Output Format**:
```groovy
tuple val(snp_group), val(prefix), path("*.grm.id"), path("*.grm.bin"), path("*.grm.N.bin")
```

**Operation**: Uses GCTA's `--make-grm` with multiple GRM files to merge partitions

## Workflow Context

These merged GRM files are used downstream in GCTA workflows:

```
MAKE_GRM_PART (per-partition) →
MERGE_GRM_PARTS (genome-wide) →
[ADJUST_GRM / REMOVE_RELATED_SUBJECTS] →
RUN_REML / RUN_FASTGWA_MLM
```
