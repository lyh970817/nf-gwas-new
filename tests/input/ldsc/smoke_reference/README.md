# LDSC Smoke Reference Files

Synthetic LDSC LD-score reference files for chromosomes 1-22 used by smoke test profiles.

Prefix to use:
- `tests/input/ldsc/smoke_reference/weights.synthetic.`

Included per chromosome:
- `weights.synthetic.<chr>.l2.ldscore.gz`
- `weights.synthetic.<chr>.l2.M`
- `weights.synthetic.<chr>.l2.M_5_50`
